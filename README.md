# The Tiny Town

Cosy isometric AI-driven village life simulation built with Unity 6 and local Ollama AI.

- Design: [GameDesignDocument.md](GameDesignDocument.md)
- Building, testing and downloading Windows builds: [Documentation/BuildAndTest.md](Documentation/BuildAndTest.md)

Status: Phase 1. One resident, Mabel, lives her day in a small isometric village with placeholder art. She has eight needs, a job at the community garden, meals, sleep and free time, all without AI yet. The town saves automatically. Controls: Space pauses, keys 1–4 set the speed, F5 saves, F9 loads, Tab switches map and F follows Mabel.

Manual test steps: [Documentation/PlaytestChecklist.md](Documentation/PlaytestChecklist.md)
